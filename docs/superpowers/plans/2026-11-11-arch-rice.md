# Arch Rice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild Mike's Hyprland desktop to match `docs/reference.png` (slate-gray Archcraft look). Add one-click wifi and bluetooth menus and a file manager that opens pictures, archives and videos properly. Never touch his files or games.

**Architecture:** `~/dotfiles` is a git repo of GNU stow packages (`<pkg>/.config/<app>/…`), symlinked into `$HOME` with `stow -t ~ <pkg>`. Old configs are copied to `~/config-backup-2026-11-11/` before they're replaced. A bash test harness, `tests/check.sh <area>`, holds an automated check for every task. It also guards the protected game paths against a baseline taken in Task 1.

**Tech Stack:**
- Desktop: Hyprland 0.55.4 (hyprlang `.conf`, not Lua), Waybar 0.15.0, Rofi 2.0.0 (Wayland native), Kitty 0.47.1, SwayNC 0.12.6

- Files and media: Thunar 4.20 + tumbler + ffmpegthumbnailer, Ristretto, File Roller, mpv + uosc
- Theming: Arc-Dark GTK (AUR), Kvantum `KvArcDark` (ships with kvantum), Papirus-Dark + papirus-folders
- Menus, dock, prompt: networkmanager-dmenu, rofi-bluetooth, nwg-dock-hyprland, starship, fastfetch, stow

**Spec:** `/home/mike/dotfiles/docs/2026-11-11-rice-design.md`. The visual spec is `/home/mike/dotfiles/docs/reference.png`.

## Global Constraints

- **Never modify, move or delete:**
  - `~/Games`, `~/.local/share/Steam`, `~/.steam`, `~/.local/share/lutris`, any Wine/Proton prefix
  - `~/Documents`, `~/Pictures`, `~/Downloads`, `~/Videos`, `~/Music`, any project folder
  - `/usr/local/bin/game-cpu-cap`, `/etc/sudoers.d/game-cpu-cap`
- Before replacing any config, copy it with `cp -a` into `~/config-backup-2026-11-11/` and keep the relative path (`.config/hypr/…`). Delete the original only after the copy is verified.
- Package removal: only `pacman -Rns <named pkgs>`, after first printing the removal list with `pacman -Rns --print <pkgs>`. Abort if the list includes steam, lutris, wine*, mangohud, nvidia*, lib32-* or networkmanager.
- Do not touch: `systemd-networkd`, NVIDIA drivers or env, kernel, bootloader, shell choice (bash stays), Neovim, VS Code, browsers.
- Palette tokens. Hex values are exact, every format uses these names, and these are the only colors allowed:

  | `surface` | `#262B33` |

- Fonts: `JetBrainsMono Nerd Font` for the bar, rofi, kitty, swaync, hyprlock and dock. `Noto Sans 10` for GTK and Qt app text.
- Hyprland, Waybar and rofi call scripts by absolute path (`$HOME/.local/bin/rice-*`), never through `PATH`.
- Hyprland 0.55 window-rule and layer-rule syntax differs from the commented examples in the old config. Check every rule against `hyprctl configerrors` (must print nothing) and the 0.55 wiki.
- Commits go on `main` of `~/dotfiles`, a new personal repo. Commit messages are short, imperative and prefixed (`hypr:`, `waybar:`, …).

## Review Focus

1. **Protected paths drift:** game and Lutris folders and the CPU-cap files must hash the same after every task. `check_protected` runs at the end of every task's test step (Task 1 owns it).
2. **Fullscreen game running:** no dim, no lock, no blur or shadow while a fullscreen window or a Steam/Lutris game is focused. Task 4 pins the rules and Task 9 pins the idle inhibit.
3. **External monitor unplugged:** bar, wallpaper and dock still appear on `eDP-1` alone, and workspaces 1–5 fall back to it. Task 6 pins this by disabling `HDMI-A-1` and checking layers.
4. **Radio switched off:** when wifi is disabled or bluetooth is rfkill-blocked, the menus still open and can turn the radio back on. Task 7 pins this.
5. **No battery** (today's hardware shows only `ACAD`): the battery module hides and idle never suspends. Task 6 and Task 9 pin this with fake sysfs fixtures.

```bash
protected_fingerprint() {   # stable hash of protected paths' tree + sizes + mtimes
  { find ~/Games ~/.local/share/Steam ~/.steam ~/.local/share/lutris -maxdepth 3 \
      -printf '%p %s %T@\n' 2>/dev/null | sort

check_protected() {

check_backup() {

           .config/rofi/config.rasi .config/kitty .config/networkmanager-dmenu/config.ini \

    assert_ok "backup has $p" test -e ~/config-backup-2026-11-11/$p; done
  assert_ok "dotfiles is a git repo" git -C ~/dotfiles rev-parse; }
```
